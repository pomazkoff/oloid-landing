# OLOID Landing

Product landing page for **OLOID** — passwordless identity for the frontline workforce and Aura identity assurance for help desks.

Stack: Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127) (dev script binds to port **43127**).

Other scripts:

```bash
npm run build   # production build
npm run start   # serve production build
npm run lint    # ESLint
```

## Project structure

- `src/app` — App Router pages and global styles
- `src/components` — landing sections and UI primitives
- `src/components/ui` — shadcn/ui components
